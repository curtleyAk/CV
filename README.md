## 🌟 Overview
An editorial, interactive public CV and developer portfolio designed for engineering leaders, Customer Success directors, and technical founders. 

Built with modern web standards, soft atmospheric ambient glows, and glassmorphic UI cards inspired by high-end digital design.

### 🛠️ Key Highlights
- **Live Cape Town Time Badge:** Real-time updating `🇿🇦 CPT [HH:MM:SS AM/PM] GMT+2` clock demonstrating EMEA operational alignment.
- **Radiating Hero Stage:** Portrait frame with floating project mockup cards (`Jenga Holacracy`, `BOA Enterprise Hub`, `Voice AI Agent`).
- **Social Proof ("Their Words, Not Mine"):** Verified enterprise partner quotes highlighting 40% ticket deflection, multi-year contract renewals, and partner retention.
- **Craft & Portfolio Bento Grid:** Showcases real full-stack repositories including:
  - **[Voys Jenga Platform](https://github.com/curtleyAk/Jenga-Holocracy):** Django Channels, WebSockets, Three.js, Redis, Docker.
  - **[BOA Enterprise Operations Hub](https://github.com/curtleyAk/BOA-HR-Hub-Vite):** React 19, Vite, Supabase.
  - **Conversational Voice AI Bot:** Retell AI, Twilio, ElevenLabs, Webhooks.
  - **1,522 Contributions Showcase:** Mini heatmap highlighting continuous commits and engineering discipline.
- **Full Printable Resume (`resume.html`):** Clean, ATS-compliant, single/double-page printable resume format with one-click print-to-PDF (`Cmd + P`).
- **One-Click Email Copy:** Clipboard copy with interactive toast notification.

---

## 💻 Tech Stack
- **Structure:** Semantic HTML5
- **Styling:** Modern CSS (CSS Custom Properties, Glassmorphism `backdrop-filter`, Flexbox, CSS Grid, Fluid Typography with `clamp()`)
- **Interactivity:** Vanilla JavaScript (ES6+, zero dependencies)
- **Typography:** Instrument Serif, Inter, JetBrains Mono
- **Hosting:** GitHub Pages (Static, zero build step required)

## 🚀 Running Locally
Simply clone and open `index.html` in your browser:
```bash
git clone https://github.com/curtleyAk/CV.git
cd CV
open index.html
```
