Full-Stack 3D Multiplayer Architecture

Voys Jenga: Real-Time 3D Holacracy Platform

Engineered with Django Channels (WebSockets), Redis, Three.js (WebGL), PostgreSQL, and Docker. Connects distributed teams through server-authoritative 3D rock-tower physics and live organisational trivia synced from the GlassFrog API.

1. Photorealistic 3D Boulder Tower & Dynamic HDRI Environments

Three.js & 8K HDRI Shaders

Renders custom 4K Namaqualand boulder meshes inside 360° South African HDRI landscapes (Klippad golden-hour sunrise and Rogland starry night) with physically based rendering (PBR) and real-time shadow mapping.

2. Interactive 3D Raycasting, Block Pulls & Summit Placement

Interactive WebGL Physics

Players orbit the camera and use 3D raycasting to highlight and extract individual rock blocks (glowing cyan on selection) before restacking them at the tower summit (glowing amber) under dynamic sunbeam lighting.

3. Live GlassFrog API Sync & "Rapid Fire" Holacracy Trivia

GlassFrog REST API + WebSockets

Synchronises live circles, roles, and accountabilities from GlassFrog to generate timed Rapid-Fire multiple-choice challenges. Answering accurately stabilises the player's safe-pull probability (`ODDS %` and `TOWER %` HUD).

4. Server-Authoritative Collapse & Recovery Loop

Django Channels + Redis State

When a risky block pull triggers a collapse, the server broadcasts the physics tumble across connected clients, tallies Rapid-Fire accuracy modifiers, and resets the room state for instant replay.
